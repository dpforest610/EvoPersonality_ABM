# tau(におい追従の強さ)の校正結果

`docs/PREREGISTRATION_scent_model.md` 改訂1の手順に従い、M2のみ、
5温度×5シード×300世代の校正パイロット
(`python3 scripts/run_scent_tau_calibration.py`、
出力 `scripts/output/scent_tau_calibration/`)を実行した。

## 選択

基準: におい追従指数(シード平均)が0.5以上になる温度のうち、最も大きいもの。

0.5以上を満たす温度: tau0/30(0.742801)、tau0/100(0.934448)。

**選択されたtau = tau0/30 = 0.033333**

この温度でのM2の移動率(校正パイロット、300世代平均)は0.449758だった。
事前登録改訂1のとおり、本番規模(5シード×1000世代)でのM2移動率の
再測定は別途行い、その値でM1のp_move(現在の暫定値0.732609、tau0での
測定)を置き換える。本ファイルはtauの選択のみを記録する。
