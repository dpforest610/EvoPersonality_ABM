# M1 (random movement, yoked control) の p_move 決定

M2(scent)のパイロット(5シード×1000世代、`python3
scripts/run_scent_spatial_sweep.py --movement scent --pilot`、
出力 `scripts/output/scent_spatial_sweep/scent_pilot/vm/`)で観測された
1フェーズあたりの移動率(`move_rate`列、各世代・各シード)から、
M1で使う固定p_moveを決めた。

## 観測された移動率(M2パイロット、5シード×1000世代、n_phases=5)

| シード | 平均move_rate(1000世代平均) |
|---|---|
| 0 | 0.732316 |
| 1 | 0.732818 |
| 2 | 0.732928 |
| 3 | 0.732142 |
| 4 | 0.732840 |

全世代・全シードをプールした平均 = **0.732609**
(シード間の標準偏差 = 0.000355 -- シード間でほぼ一定)

## 決定

**p_move = 0.732609** を M1(ランダム移動)のパイロット・本番で使う
固定値とする。

この値はM2パイロットの観測値のみから決めており、M1のパイロット・
本番データはこの決定に一切使わない(事前登録0節: パイロットの
データは本番の解析に混入させない、という方針と同じ理由で、
p_move決定用のM2パイロットと、M1自身のパイロット/本番ランは
別物として扱う)。

## 改訂(tau校正後の再測定)

事前登録改訂1(`docs/PREREGISTRATION_scent_model.md`)のtau校正により、
tau=0.033333(tau0/30)を採用した
(`docs/SCENT_MODEL_TAU_CALIBRATION_DECISION.md`)。この新しいtauで
M2を本番規模のパイロットと同じ条件(5シード×1000世代、`python3
scripts/run_scent_spatial_sweep.py --movement scent --tau 0.033333
--pilot --out-suffix _v2`、出力
`scripts/output/scent_spatial_sweep/scent_pilot_v2/vm/`)で再実行し、
移動率を測り直した。

### 観測された移動率(tau=0.033333、5シード×1000世代)

| シード | 平均move_rate(1000世代平均) |
|---|---|
| 0 | 0.560298 |
| 1 | 0.513170 |
| 2 | 0.567404 |
| 3 | 0.562278 |
| 4 | 0.545272 |

全世代・全シードをプールした平均 = **0.549684**
(シード間の標準偏差 = 0.022011 -- tau0での測定(0.000355)より
シード間のばらつきが大きい。tauが小さいほど、移動判断が実際の
局所的な利得分布に左右されるため、シードごとの集団構成の違いが
移動率に反映されやすくなることと整合する)。

### 決定(更新)

**p_move = 0.549684** に更新し、以後のM1(ランダム移動)のパイロット・
本番ではこちらを使う。tau0(1.0)での旧値0.732609は、tau0のM2
(「弱いにおい」、事前登録Cの記述的比較に残す)に対応する参考値として、
上記に記録を残す。
