## 1. β_self の変化の分解: 標本構成の効果 vs 定式化の効果

4列:
- `full4` = 全個体・4変数回帰(文脈回帰、β_selfの項)= 既存の「事前登録どおり」の値
- `full2` = 全個体・自己2変数のみの回帰(文脈の列を含めない)
- `excl2` = 孤立個体を除いた個体・自己2変数のみの回帰
- `excl4` = 孤立個体を除いた個体・4変数回帰 = 既存の「孤立除外版」の値

`full4`→`full2`の差は定式化の効果を含まない(後述)。`full2`→`excl2`の差が標本構成の効果
(孤立個体を除いたことそのもの)。`excl2`→`excl4`の差が定式化の効果(文脈の列を加えたことによる、
同じ標本内での変化)。
