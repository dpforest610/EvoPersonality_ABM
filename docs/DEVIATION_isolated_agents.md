## 背景

事前登録で固定された文脈回帰(`scripts/analyze_scent_production.py` の `context_lande_arnold`。
N=1000 の実行中に同じ計算をした `scripts/run_scent_spatial_sweep_n1000.py` の `compute_seed_summary` も同じ)は、
その世代に対戦0回の個体が1体でもいると、次のように動く。

1. その個体の相手平均(`opponent_mean_k_self`、`opponent_mean_k_out`)は NaN になる。
2. 列の標準偏差が NaN になり、`NaN > 0` が偽になる。
3. その列全体が0に置き換えられる。
4. その結果、β_ctx(K_self)・β_ctx(K_out) がちょうど0になる。

該当する世代の割合(gen>=2000、100世代ごとのスナップショット)は次のとおり。

| | M0 | M1 | M2 | M1-low | M2-low |
|---|---|---|---|---|---|
| N=1000 | 91.0% | 2.4% | 0.2% | 92.9% | 83.1% |
| N=100 | 19.1% | 0% | 0% | — | — |

## 決定

1. **不具合としての判断。** 事前登録どおりの計算では、孤立個体が1体でもいると文脈の列が丸ごと0になる。
   これは実装の不具合であり、事前登録が意図した分析(β_ctx の推定)ではないと判断する。

2. **主要検定の正式な値。** 主要検定 A(M2 vs M1)と A2(M2-low vs M1-low)の正式な値は、
   各世代で対戦0回の個体を回帰から除いた版とする。検定法(Mann-Whitney U、両側)、有意水準、
   比べる向き(M2 対 M1、M2-low 対 M1-low)は、事前登録のまま変えない。

3. **事前登録どおりの計算の値も報告する。** すべての値を、除外版と並べて報告する。

4. **N=100 にもさかのぼって当てはめる。** 同じ規則を N=100 にも当てはめ、両方の版を並べて報告する。

5. **追加で報告すること(探索的):**
   - 条件ごとの孤立割合。
   - 孤立個体を除いた版と含めた版の β_self(K_self)、β_self(K_out)。
   - β_ctx(K_out) ~ is_scent + move_rate の ANCOVA。**第1群(M1・M2)のみ**とする。
     第2群(M1-low・M2-low)は is_scent と move_rate がほぼ重なっているため、解釈しない。

6. **第2群の assortativity の ANCOVA**(k_out_assortativity ~ is_scent + move_rate、M1-low・M2-low)も、
   同じ理由(is_scent と move_rate がほぼ重なっている)で解釈しないと明記する。

## 除外の規則(実装上の定義)

- 各スナップショット世代で、`opponent_mean_k_self` または `opponent_mean_k_out` が NaN の個体
  (その世代に1回も対戦していない個体)を除く。残った個体で、その世代の文脈回帰を計算する。
  標準化と、適応度 w = payoff / mean(payoff) の正規化も、残った個体の中で行う。
- 除外したあとの配列で、5変数(K_self、K_out、payoff、相手平均 K_self、相手平均 K_out)のどれかが
  1種類の値しか持たない世代は、その世代を使わない(事前登録版の規則を、除外後の配列に当てはめたもの)。
- それ以外(gen>=2000、シード内中央値、条件内 n、検定)は事前登録版と同じ。
- 実装: `scripts/analyze_scent_production_n1000.py` の `seed_ctx_both_variants`。
  N=100 はコミット済みの `seed_*_individual_log.csv`、N=1000 は実行マシンの `seed_*_individual_log.csv.gz` を読む。

## 影響を受けない値

自分の形質だけの Lande-Arnold 係数(β1、β2、γ11、γ22、γ12)、z\*、分散・二峰性係数、操作チェックの指標
(似かた・移動率・孤立割合など)は、相手平均を使わないので、この決定の影響を受けない。
