## 1. 問い

記憶の深さが進化する Lindgren の集団から取り出した「仮想参加者」に、人の実験と同じ5つの相手
(TFT・Random・AllC・AllD・Gradual)と同じ条件で対戦させ、人の研究と同じ3ステップのマルコフ網を作る。
その網の構造が、人の愛着3群(Secure・Mix・Fearful)のどの網に近いかを、進化の流れの中で調べる。

## 3. 本番の設計(固定)

- モデル:K のない純粋な Lindgren モデル(population.py の run_evolution)。
  population=100、rounds_per_duel=50、point_mutation=0.05、duplication=0.02、split=0.02、max_memory_depth=6。
- seed:100〜169 の 70 本。世代数 5000(これまでの章とそろえる)。
- ノイズ(実行誤り):**0.01 を主条件**、0.0 を感度分析。
- プローブ:50世代おき。各遺伝子型 × 相手 × 30反復、1対戦100ラウンド、分析には1〜20回目を使う。
  Gradual は「相手の裏切りを見た次の手から報復、裏切りの回数は罰の最中も含めて全回数」(人の実験と同じ)。
- 網の定義:参照実装(markov3_widest_path_reference.py、人のデータで論文の値を完全再現済み)と同じ。
  参加者ごとの3-gram の集合、後ろ2文字=前2文字の辺、参加者単位の Jaccard。
- 群の作り方(2通り):
  - **(B) 系統間抽出 = 主分析**:同じ時点について、別々の seed から1体ずつ(各 seed 内では頻度に比例して)
    抽出し、人の群と同じ人数(56・46・69)の群を作る。
  - (A) 集団内抽出 = 比較:一つの seed の集団から、頻度に比例して同じ人数を抽出する。
- 分析の時間窓:**gen 1000〜5000 のプローブ時点の平均**(パイロットで初期の過渡期が gen 500 前後まで見られたため)。

## 4. 確証的な仮説(主条件:系統間抽出、ノイズ 0.01、人数は各比較で人の該当群の人数)

指標:進化した網の辺の重みベクトルと、人の各群の網の重みベクトルとのピアソン相関
(両方の網の辺の和集合を取り、片方にない辺は 0 とする)。r(S)、r(M)、r(F) と書く。

- **H1(TFT)**:r(M) > r(S)、かつ r(F) > r(S)。
- **H2(AllD)**:r(M) < r(S)、かつ r(M) < r(F)。
- **H3(AllC)**:r(F) > r(S)、かつ r(F) > r(M)。

計6つの方向つき比較。

## 5. 推測の方法

- 点推定:系統間抽出を 1000 回繰り返し、各回で時間窓内の平均相関を計算し、その平均を点推定とする。
- 不確かさ:**seed を単位としたブートストラップ**(70 seed を復元抽出で 70 本選び直し、その seed 集合から
  系統間抽出で群を作って差を計算する、を 2000 回)。系統の有限性による不確かさを表すため、
  同じ seed 集合からの抽出の繰り返しではなく、seed の選び直しで幅を出す。
  (復元抽出で同じ seed が複数回選ばれた場合は、その seed から別々の個体を抽出する。)
- 判定:各比較について、片側 p = (差が 0 以下になったブートストラップの割合)を求め、
  6つの比較に Holm 法を適用して α = .05 で判定する。
- 各仮説(H1〜H3)は、含まれる2つの比較が両方とも有意のとき「支持」、一方のみのとき「部分的に支持」、
  どちらも有意でないとき「支持されない」とする。
