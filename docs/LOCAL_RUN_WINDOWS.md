# 精密kスイープ延長ラン(k=99, 64, 80)を Windows でそのまま実行する

Ubuntu/WSLやコマンド操作に慣れていなくても大丈夫なように、ダブルクリックで
操作できるファイルを用意した。最初だけ少し準備が必要だが、それ以降は
「setup_windows.bat をダブルクリック → start_run.bat をダブルクリック」で済む。

対象ブランチ: `claude/lindgren-population-evolution-08fat1`
対象リポジトリ: `dpforest610/EvoPersonality_ABM`

---

## 0. 引き継ぎ時点の進捗

| k | 完了シード数 | 進行中チェックポイント(seed: 到達世代/5000) |
|---|---|---|
| 99 | 16/50 | seed16: 1000, seed17: 500, seed18: 500, seed19: 500 |
| 64 | 0/50 | なし |
| 80 | 0/50 | なし |

合計 16/150。進行中の4シードも、保存済みの世代まではそのまま使われる(下の手順で取り込む)。

---

## 1. 必要なソフトを入れる(最初の1回だけ)

### 1-1. Python

1. https://www.python.org/downloads/ を開く
2. 「Download Python 3.x.x」という黄色いボタンをクリックしてインストーラーをダウンロード
3. ダウンロードしたインストーラーを実行する
4. **最初の画面の下の方にある「Add python.exe to PATH」に必ずチェックを入れる**(これを忘れると、あとの手順がすべて失敗する)
5. 「Install Now」をクリックしてインストール完了まで待つ

### 1-2. Git for Windows

1. https://git-scm.com/download/win を開く
2. 自動でダウンロードが始まるので、インストーラーを実行する
3. 基本的にすべて「Next」のままでよい(設定画面がいくつも出るが、初期値のままで問題ない)

### 1-3. GitHubへのログイン(GitHub Desktop)

コマンド操作なしでログインできる、GitHub Desktop を使う。

1. https://desktop.github.com/ を開き、「Download for Windows」をクリック
2. インストーラーを実行し、インストール完了を待つと自動で起動する
3. 「Sign in to GitHub.com」をクリックし、ブラウザでログインする(普段使っているGitHubアカウントで)
4. ログインできたら、GitHub Desktop はこの後も裏で認証情報を使ってくれるので、立ち上げたままにしておく(最小化してよい)

### 1-4. リポジトリをPCに持ってくる

GitHub Desktop で:

1. 左上「File」→「Clone Repository」
2. 「URL」タブを選び、`https://github.com/dpforest610/EvoPersonality_ABM` と入力
3. 「Local Path」で保存先フォルダを選ぶ(そのままでよい。例: `C:\Users\<あなたの名前>\Documents\GitHub\EvoPersonality_ABM`)
4. 「Clone」をクリック

クローンが終わったら、作業ブランチに切り替える:

1. GitHub Desktop の上部中央「Current Branch」をクリック
2. 検索欄に `lindgren-population-evolution` と入力し、候補から
   `claude/lindgren-population-evolution-08fat1` を選ぶ

これで、PC上のフォルダの中身がこの作業ブランチの内容になる。

---

## 2. セットアップ(ダブルクリック1回)

Windowsのエクスプローラーで、クローンしたフォルダ(例: `EvoPersonality_ABM`)を開き、
**`setup_windows.bat` をダブルクリック**する。

黒いウィンドウが開いて、以下を自動で行う:

- venv(Python専用の作業環境)を作成
- 必要なパッケージをインストール
- クラウド側で進行中だったチェックポイントを取得
- テストを実行して、全部正しく動くか確認
- 現在の進捗を表示

「セットアップ完了。次は start_run.bat をダブルクリックしてください。」と表示されたら成功。
**何かキーを押すまでウィンドウは閉じないので、エラーが出た場合は赤い `[ERROR]` の行をそのまま報告してほしい。**

もし「Windows によって PC が保護されました」という青い画面が出た場合は、
「詳細情報」→「実行」をクリックする(このファイルは自分のリポジトリから来た .bat ファイルであることの確認)。

---

## 3. 起動

**`start_run.bat` をダブルクリック**する。

- このPCのコア数を自動で調べ、「コア数−1」のワーカー数で起動する
- 「起動しました。このウィンドウは閉じて構いません。」と表示されたら、ランは裏側の非表示プロセスとして動き始めている
- **採用した方式**: 「このウィンドウを閉じても処理は続く」方式を選んだ(「閉じないでください」と表示される最小化ウィンドウ方式は採用しなかった)。間違えてウィンドウを閉じても、ランは止まらない。
- このウィンドウ自体は、何かキーを押すと閉じられる(閉じてもランには影響しない)

もし「すでに実行中です」と表示されたら、二重起動はされていない(安全に終了してよい)。

---

## 4. 進捗確認

**`check_progress.bat` をダブルクリック**する。

- k=99, 64, 80 それぞれの完了数(/50)と、進行中シードの到達世代
- プロセスが実際に動いているか(PID付きで表示)
- ログの直近20行

確認が終わったら、何かキーを押すとウィンドウが閉じる。

---

## 5. 停止

**`stop_run.bat` をダブルクリック**する。

- 動いているプロセスを安全に終了する
- 終了のタイミングによって、直前のチャンク(最大500世代、k=99で最大約12分)分の
  計算だけが失われる可能性があるが、それより前の進捗はチェックポイントに
  保存されているので、次に `start_run.bat` を実行すれば続きから再開される

---

## 6. 学校に持っていくとき

1. 家を出る前に **`stop_run.bat`** をダブルクリックして停止する
2. (任意)**`check_progress.bat`** で、ちゃんと止まったことを確認する
3. 帰宅後、電源とネットワークにつないだら **`start_run.bat`** をダブルクリックするだけで、続きから再開される

---

## 7. ノートPCの注意

### 電源アダプタを必ず接続する

バッテリーのみでは、Windowsの省電力設定によって動作が遅くなったり、
長時間のランには向かない。ランを走らせている間は、必ずACアダプタを
接続しておく。

### 「ふたを閉じたときの動作」を「何もしない」に変更する

初期設定では、ノートPCのふたを閉じるとスリープしてしまい、ランが止まる。
これを防ぐには:

1. Windowsの検索バーで「電源とスリープの設定」と入力して開く
2. 右側の「関連設定」から「電源の追加設定」(または「電源ボタンの動作を選択する」)を開く
3. 「現在利用可能ではない設定を変更します」をクリック
4. 「カバーを閉じたときの動作」の「電源に接続」の項目を「何もしない」に変更
5. 「変更の保存」をクリック

(`start_run.bat` は内部でWindowsに「システムをスリープさせないでほしい」と
伝えているが、これは画面を閉じたときの「スリープする/しない」という
Windows自体の設定より弱いため、上記の設定変更もあわせて行っておくと安全。)

## 8. 結果の回収

全150ユニット完了(`check_progress.bat` で `Total: 150/150`)したら、
GitHub Desktop で:

1. 左側に `scripts/output/opponent_count_precision_sweep/` 配下の変更が
   表示されているはず(通常は実行中に自動でコミット・pushされているので、
   ここには最後の分だけが残っているはず)
2. 下の「Summary」欄に適当なコメント(例: `Local run: final results`)を入力
3. 「Commit to claude/lindgren-population-evolution-08fat1」をクリック
4. 右上の「Push origin」をクリック

その後の「ステップ2解析一式」の実行は、Pythonのコマンドをいくつか打つ必要が
あるので、ここまで終わったら一度声をかけてほしい。

## 9. トラブル時

| 症状 | 対処 |
|---|---|
| `setup_windows.bat` が `Python が見つかりません` で止まる | 1-1を再確認。インストール時に「Add python.exe to PATH」にチェックを入れたか。入れ忘れた場合は、Pythonをアンインストールしてから入れ直すのが確実 |
| `setup_windows.bat` の途中でネットワーク関連のエラーが出る | インターネット接続を確認してから、もう一度 `setup_windows.bat` をダブルクリックする(venvなど、できている部分はスキップされて途中から進む) |
| `start_run.bat` を実行しても `check_progress.bat` で進捗が増えない | 数分待ってから再確認する(1チャンク=最大十数分かかる)。増えないまま30分以上経過したら、ログ(`logs\sweep_run.log`)の内容を報告してほしい |
| 「Windows によって PC が保護されました」と出る | 「詳細情報」→「実行」をクリックして進める(自分のリポジトリのファイルなので問題ない) |
| ディスク容量不足 | 一度 `stop_run.bat` で停止し、不要なファイルを整理してから `start_run.bat` で再開する |
| GitHub Desktop で「Push」がうまくいかない | 「Fetch origin」→「Pull origin」を試してから、もう一度「Push origin」。コンフリクトが出た場合は、そのまま声をかけてほしい |
