## 改訂1: tau(におい追従の強さ)の校正

初回パイロット(M0・M1・M2、各5シード×1000世代、既定値tau0=1.0)の結果、
M2の移動率(0.7328)が、密度0.59・ムーア近傍で「とどまる+空きマス」から
一様に選んだ場合の理論値(1 - 1/(平均空きマス数+1) ≈ 0.75、既定値tauでの
観測movement rateとほぼ同じ)に近く、においのスコアが移動先の選択に
ほとんど効いていない可能性が高いと判断した。M2とM1の対戦ペアK_out似かた
(0.0749 vs 0.0716)もほぼ同じで、これを裏付ける。そこでM2のsoftmax温度
tauの校正を、本番前に行う。

### におい追従指数の定義

M2の各移動判断について(候補 = {とどまる} + {空きマス}):

    (選んだ候補のスコア - 候補スコアの平均) / (候補スコアの最大 - 候補スコアの平均)

候補スコアの最大=平均の場合(情報がない)はその判断を除外する。一様ランダムな
選択なら期待値約0、常に最高スコアの候補を選ぶなら1になる。
`evopersonality_abm/scent_spatial.py`の`ScentGenerationStats.scent_index_mean`
として、既存の移動判断ロジック・乱数消費を一切変えずに(スコア計算後の
付帯統計として)実装済み。movement="scent"以外ではNaN。

### 温度の候補

既定値 tau0(=1.0)と、tau0/3, tau0/10, tau0/30, tau0/100
(= 1.0, 0.333333, 0.1, 0.033333, 0.01)の5つ。

### 選択基準

におい追従指数の世代平均をさらにシード平均したものが0.5以上になる温度の
うち、**最も大きい(最も穏やかな)もの**を選ぶ。候補のどれも0.5に届かなければ、
その旨を報告してここで停止する(校正パイロット後に恣意的に基準を
緩めない)。

**温度の選択には、β・協力率・似かた(assortativity)など結果側の指標は
一切使わない。** 選択はにおい追従指数のみで行う。

選ばれた温度でM2の移動率を測り直し、M1のp_move(現在の暫定値0.732609、
tau0での観測値)を、その新しい測定値で置き換える。既定値tau0のM2
(「弱いにおい」)は、校正後の本番データとは別に、事前登録Cの記述的比較に
残してよい(新たな有意性検定の対象にはしない)。

## 0. パイロットと本番の分離(重要)

**パイロットのデータ(上記3a・3bの計5シード×1000世代×3条件、
p_move決定用のM2ランを含む)は、本番の解析に一切使わない。**
本番は別に、各条件50シード×5000世代で最初から走らせる。パイロットの
データが本番の解析(主要評価A、副次評価B、記述的報告C)に数値として
混ざることはない。パイロットが本番に渡す情報は「M1に使うp_moveの値」
(ひとつの数値、パラメータの決定)だけであり、それ以外の形でパイロットの
観測値が本番の統計量に混入しないことをここで明記する。

## A. 主要評価(確定、変更しない)

文脈分析(Heisler & Damuth 1987形式、下記B参照)のβ_ctx(K_out)
(対戦相手のK_out平均の係数)を、gen>=2000・per-seedの中央値(n=50シード)で、
M2(scent) vs M1(random)でMann-Whitney U(両側)で比較する。これが本実験の
唯一の確証的検定であり、単一の比較(多重比較補正は不要)。

## B. 副次評価

### (a) 対戦ペアのK_outの似かた: M2 vs M1

`k_out_assortativity`(実際に対戦したペアについてのK_outのPearson相関、
環状モデルと同じ定義)を、gen>=2000・per-seed中央値(n=50シード)で
M2 vs M1でMann-Whitney U(両側)を報告する。対立する2つの仮説をここに
明記し、どちらの形がデータに現れるかを(検定の向きを決めずに)報告する:

- **仮説A(似た者が集まる)**: においによる移動は「利得の高い近傍」を
  目指すものであり、利得が高い近傍はしばしば形質の近い個体同士(同じ
  戦略・似たK)で構成されるため、M2はM1より似かたを**上げる**。
- **仮説B(搾取的な引き寄せ)**: においのスコアは形質の類似性ではなく
  純粋に相手の利得で決まるため、裏切り者が協力者の近くに引き寄せられる
  (協力者に囲まれた裏切り者は利得が高いが、その近傍自体は形質的には
  似ていない個体の集まりになる)ことで、M2はM1より似かたを**下げる**。

### (b) 定量予測: 環状モデル局所配置の4点からの予測区間

環状モデルのplacement="local"実験(本番データ、gen>=2000・per-seed中央値、
n=50シード、k=4,8,16,32)の4点、(x=k_out_assortativity, y=β_ctx(K_out))に
単回帰直線をあてはめ、95%予測区間を**パイロットを走らせる前に**計算した
(`scripts/precompute_ring_assortativity_vs_beta_ctx_prediction.py`、
再現可能なスクリプトとしてコミット済み)。

**4点(環状モデル、local条件)**:

| k | x = k_out_assortativity(seed中央値) | y = β_ctx(K_out)(seed中央値) |
|---|---|---|
| 4 | 0.701415 | -0.004922 |
| 8 | 0.590494 | -0.004600 |
| 16 | 0.438302 | -0.003703 |
| 32 | 0.255851 | -0.001739 |

**OLS回帰(n=4)**:

    y_hat(x) = -0.00016799 + (-0.00719578) * x

r = -0.972144 (r^2 = 0.945064)、傾き≠0のp値 = 0.027856(自由度2)、
残差標準誤差 s = 0.00041078(自由度2)、
x_bar(xの平均) = 0.496515、Sxx = 0.11212395、
t_crit(両側95%、自由度2) = 4.302653。

**新しい1点x0に対する95%予測区間の式**:

    y_hat(x0) = -0.00016799 - 0.00719578 * x0
    PI(x0) = y_hat(x0) +/- 4.302653 * 0.00041078 * sqrt(1 + 1/4 + (x0 - 0.496515)^2 / 0.11212395)

パイロット・本番でM0・M1・M2それぞれの観測されたk_out_assortativityが

**実際に観測されたβ_ctx(K_out)がこの予測区間に入るかどうか**を報告する。
入らない場合は「環状モデルの似かた-β_ctx(K_out)関係が、2次元空間モデルには
そのまま当てはまらない」ことを示す結果として、その旨のみ報告し、解釈は
行わない。

### (c) 次元・混合の効果

- M0(2次元、移動なし) vs 環状モデルのplacement="local"(次元の違いを
  見る比較): 両者のk_out_assortativity・β_ctx(K_out)を並べて報告する。
- M1(ランダム移動) vs M0(移動なし)(混ざることの効果): 
  k_out_assortativity・β_ctx(K_out)・協力率を並べて報告する。
- いずれも記述的比較とし、(a)の検定以外に新たな有意性検定は設けない。
